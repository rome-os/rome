# Concierge

Each owner's Concierge: its main chat and topic chats, the task chats it hands work to, its follows and tasks, and the digests, alerts and pushes it sends.

## Imports

- Concierge may import Access, Agents, Apps, Chats, Connections, Instance, Routines and Webchat, as [`lint/rules/contexts.ts`](../../../../lint/rules/contexts.ts) checks.
- It is imported by App host only.
