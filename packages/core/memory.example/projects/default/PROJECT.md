# Default Project

The default project when the guardian does not select a project.

## Details

The first paragraph after the title is a one-line summary of what the project is. Keep it within 160 Unicode code points.
Leave a blank line between that summary and this section. Only the summary loads automatically into the main agent's project context.

Put project structure, commands, conventions, decisions, and current work here. Keep these details out of the summary and read them on demand.
