# Rome Computer Use for Apple Silicon

This package contains the signed and notarized `Rome Computer Use.app` for
arm64 macOS. Install `@rome-os/node` or `@rome-os/node-core` to get the
helper as an optional dependency. See the
[Rome Node documentation](https://github.com/rome-os/rome/blob/main/docs/rome-node.md#screen-control-on-macos)
for discovery and macOS permissions.
