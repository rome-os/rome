# Component Specs

One spec per component, each covering the parts of the component, the semantic tokens each part consumes, and the component tokens scoped to it. [ui-component-tokens.md](../../authoring/ui-component-tokens.md) is the rulebook, and holds the required sections and the admission bar. [../../authoring/ui-tokens.md](../../authoring/ui-tokens.md) holds the terminology.

[../component-roles.md](../component-roles.md) holds the contract a spec's component inherits from its role — its size scale, its focus geometry, what it may and may not set. A spec states what is true of that one component. Anything true of the whole role belongs there instead.
